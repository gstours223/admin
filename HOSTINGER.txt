GS Tours — Hostinger Business (Node.js Web App)
================================================

This is a Node.js CRM, not WordPress. Do not upload it into public_html
with File Manager. Use: Websites → Add Website → Node.js web app.

1) Plan
   Business Web Hosting is enough.

2) Database (required)
   Hostinger MySQL will NOT work. The desk needs PostgreSQL.

   Easiest: create a free project at https://supabase.com or https://neon.tech
   Copy the Postgres connection URI (it starts with postgresql://).

   In Supabase: Project Settings → Database → Connection string → URI
   (use the "direct" or "session" URI, and replace [YOUR-PASSWORD]).
   That is DATABASE_URL. Do NOT use the anon/public API key.

3) Upload
   In hPanel:
     Websites → Add Website → Node.js web app → Upload your files
   Upload gstours-hostinger.zip
   (If the domain already has a website on this plan, remove that slot first.)

4) Build settings
   Node.js version     22
   Framework           Nitro   (or Other if Nitro is not listed)
   Build command       npm run build:hostinger
   Output directory    .output
   Entry file          server/index.mjs
                       (if it rejects that, try .output/server/index.mjs)

5) Environment variables (add BEFORE you deploy, or redeploy after)
   DATABASE_URL         postgresql://USER:PASSWORD@HOST:5432/postgres
   BETTER_AUTH_URL      https://YOUR-DOMAIN
   BETTER_AUTH_SECRET   a long random string (keep it private)
   NITRO_PRESET         node-server
   NODE_ENV             production

   Generate a secret: any long random line of letters and numbers (32+ chars).

6) Domain + SSL
   Attach your GS Tours domain to this Node.js website. SSL is included.
   Do not edit .htaccess in public_html — Hostinger regenerates it.

7) First login
   Open https://YOUR-DOMAIN
   Team sign in → create the first account
   Then: Settings (KvK, IBAN, Hostinger SMTP) and optionally Restore backup.

8) Send invoices from Hostinger mail
   After login go to Settings:
     SMTP host     smtp.hostinger.com
     Port          465
     User          your Hostinger email (e.g. info@gstours.nl)
     Password      that mailbox password
     From          same address

If the build is green but the site is blank, open Runtime logs.
Usual cause: DATABASE_URL missing or wrong, or entry file path.
